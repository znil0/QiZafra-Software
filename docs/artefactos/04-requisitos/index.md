# Los Requisitos

Realizamos una investigación breve sobre lo que son los requisitos en el contexto de la Ingeniería de Software. Encontramos lo siguiente.


## Características de un Buen Requisito

Para garantizar la calidad de un sistema informático, los requisitos deben cumplir con las siguientes características esenciales:

i. **Específico:** No debe prestarse a interpretaciones o ambigüedades; debe significar lo mismo para desarrolladores y usuarios.
ii. **Verificable:** Debe ser posible diseñar pruebas físicas o de software para confirmar si el sistema cumple o no con el requisito.
iii. **Completo:** Debe contener toda la información necesaria para que los desarrolladores puedan implementarlo sin asumir datos faltantes.
iv. **Consistente:** No debe entrar en conflicto con otros requisitos definidos dentro del mismo sistema.
v. **Factible:** Debe ser realizable dentro de las limitaciones técnicas, presupuestarias y de tiempo del proyecto.
vi. **Rastreable:** Debe ser posible seguir el origen del requisito (desde la necesidad del cliente) hasta su diseño, código y pruebas.


## Tipos de Requisitos

I. **Requisitos Funcionales:** Son enunciados acerca de servicios que el sistema debe proveer, de cómo debería reaccionar el sistema a entradas particulares y de cómo debería comportarse el sistema en situaciones específicas. En algunos casos, los requerimientos funcionales también explican lo que no debe hacer el sistema.

II. **Requisitos No Funcionales:** Son limitaciones sobre servicios o funciones que ofrece el sistema. Incluyen restricciones tanto de temporización y del proceso de desarrollo, como impuestas por los estándares. Los  requerimientos no funcionales se suelen aplicar al sistema como un todo, más que a características o a servicios individuales del sistema. (Sommerville, 2011, pp. 84-86)

III. **Requisitos de Dominio:** Son requisitos derivados del área de aplicación o contexto del negocio (reglas del sector, legislación, terminología especializada o restricciones operativas propias de la industria).
