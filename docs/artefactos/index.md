# Artefactos

Esta sección reúne los productos de trabajo generados durante el curso de **Fundamentos de Ingeniería de Software**. Naturalmente, al tratarse de un proyecto académico del cuál estamos aprendiendo, mi equipo y yo realizamos las partes del desarrollo mediante entregables que aquí serán llamados Artefactos. Estos entregables incluyen entrevistas, listados de requisitos, descripciones y documentos especializados como el Charter del proyecto.

Estos entregables fueron o serán entregados como parte de nuestras evidencias de trabajo y optamos por agregarlos aquí para mantener un orden claro y un registro actualizado de todo nuestro trabajo. Conforme vayamos haciendo cambios en el desarrollo; como por ejemplo, añadir una función extra o cambiar nuestro enfoque en una área, procuraremos actualizar todos los documentos para evitar el desfase de la información.


# Índice
A continuación se enlistan todos los artefactos generados en la asignatura.

1. `A01 Primera Entrevista`. La primera entrevista que realizamos para obtener información preliminar sobre el posible proyecto y analizar necesidades.
2. `A02 Charter`. El documento de descripción y formalización del proyecto. Este contiene información relacionada a los clientes, los desarrolladores, presupuesto, entre otros.
3. `A03 Diagrama BPMN`. El esquema que representa el proceso general que se sigue dentro de la empresa.
4. `A04 Requisitos`. Contiene el listado pormenorizado de requisitos funcionales, no funcionales y de dominio que regirán el desarrollo del sistema.
5. `A05 Segunda Entrevista`. La segunda entrevista realizada, para afinar los detalles de los requisitos.
