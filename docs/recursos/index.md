# Recursos

Esta sección reúne las decisiones de diseño y otros extras que hemos ido añadiendo para darle personalidad y color al proyecto. Incluye elementos como logos, paletas de colores, esta propia página de documentación y más. Nótese que esta sección no contiene entregables ni artefactos sujetos a rúbricas, por lo que su contenido es más laxo en comparación de las demás secciones. *Aquí añadiremos comentarios y anotaciones.*
